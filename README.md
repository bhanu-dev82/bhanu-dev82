Mobile engineer and indie app developer with 2+ years of experience shipping production Android and Flutter apps on Google Play. Founder of **Devanshu Studios** — building apps that people actually use.

- 📱 **Founder @ Devanshu Studios** — shipped **[Chakuli](https://github.com/bhanu-dev82)** (offline AI chatbot, on-device LLM via LiteRT-LM, closed beta) and **[PyMaster](https://play.google.com/store/apps/details?id=com.devanshustudios.pymaster)** (Python learning platform, 50k+ LOC, live on Play Store)
- 🤖 **On-Device AI** — running Gemma 2/3, Phi 3.5 Mini, SmolLM on Android hardware via LiteRT-LM; zero cloud calls for inference
- 🌍 **Globalink Research Intern @ Mitacs** — sole developer of a cross-platform Flutter app; presented at an international symposium in Canada
- 🧠 **ML Intern @ Athabasca University** — 95% accuracy on text ideology classification using BERT/Transformers
- 🔓 **Open Source @ Wikimedia Foundation** — Scribe-Android (Kotlin), tablet keyboard layouts for 7+ languages
- 📄 **Published** in IGI Global & ACM · **Patent** holder (granted) · **₹10 lakh grant** awardee
- ✍️ **Technical writer on Medium** — production postmortems and engineering deep-dives
